# Who can use the editing controls?

<!-- type: faq -->
<!-- category: getting-started -->
<!-- tag: moderation,permissions -->
<!-- seo-title: %%post_title%% - %%sitetitle%% -->
<!-- seo-description: Learn which moderators can use forumManager controls. -->
<!-- seo-keywords: moderators,permissions -->

Keymasters can use the plugin. Global moderators can use it when their setting is enabled. The separate forum moderator setting allows users with individual moderation capability to access applicable topic controls. Forum-list editing is reserved for keymasters and enabled global moderators. See [Getting Started Panel](panel-dashboard.md) for the settings and defaults.
