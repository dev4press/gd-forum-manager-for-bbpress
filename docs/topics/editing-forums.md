# Editing Forums

<!-- category: features -->
<!-- tag: forums,moderation -->
<!-- seo-title: %%post_title%% - %%sitetitle%% -->
<!-- seo-description: Change forum title, status, and visibility from the frontend. -->
<!-- seo-keywords: forum edit,bulk edit -->

With **Edit Forums** enabled, keymasters and allowed global moderators can use the controls on frontend forum lists. See [Quick and Bulk Editing](quick-and-bulk-editing.md) for the steps.

![Edit Forum dialog showing title, status, and visibility](forum-edit-dialog.png)

For one forum, the dialog can change its **Title**, **Status**, and **Visibility**. Bulk editing can change **Status** and **Visibility** for the selected forums; it does not rename them. The available status and visibility choices come from bbPress. Review visibility changes carefully because they affect who can see a forum.
