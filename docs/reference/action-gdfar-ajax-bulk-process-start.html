Definition
do_action( "gdfar_ajax_bulk_process_start", $data );
Arguments
Name
Type
Description
$data
array
Request data for the bulk operation; submitted field values are not sanitized as a whole.

Runs after nonce and moderation checks, immediately before processing for a bulk forum or topic edit. The hook does not run for requests rejected by those checks. Validate field values before use. Type-specific variants also fire with forum or topic inserted after bulk.
