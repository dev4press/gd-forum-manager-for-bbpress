Definition
apply_filters( "gdfar_control_forum_edit", $label );
Arguments
Name
Type
Description
$label
string
The translated forum-list edit link text.
Returns
Return the text to display.

Filters the forum-list edit link text. The initial translated text is "edit". Runs when the corresponding forum control is rendered; the value is escaped as text or as an attribute. No object ID is passed to this filter.
