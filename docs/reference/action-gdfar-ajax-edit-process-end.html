Definition
do_action( "gdfar_ajax_edit_process_end", $data, $result, $changes );
Arguments
Name
Type
Description
$data
array
Request data for the edit operation.
$result
array|WP_Error
Field error messages keyed by action name, or a WP_Error for an operation-level error.
$changes
array
Recorded changes for the edited object, keyed by field.

Runs after processing and collecting recorded changes, before the AJAX response for an individual forum or topic edit. The hook also fires when processing reports errors; other changes may have succeeded. Type-specific variants also fire with forum or topic inserted after edit.
