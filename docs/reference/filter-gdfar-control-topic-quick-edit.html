Definition
apply_filters( "gdfar_control_topic_quick_edit", $label );
Arguments
Name
Type
Description
$label
string
The translated Quick Edit link text.
Returns
Return the text to display.

Filters the Quick Edit link text. The initial translated text is "Quick Edit". Runs when the corresponding topic control is rendered; the returned value is inserted into the link markup without escaping. Return safe text or trusted markup. No object ID is passed to this filter.
